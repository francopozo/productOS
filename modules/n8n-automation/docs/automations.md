# Automatizaciones

Catalogo base para definir automatizaciones n8n.

## Plantilla Sugerida

Para cada automatizacion documenta:

- nombre
- objetivo
- trigger
- entradas
- transformaciones
- salidas
- errores esperados
- dependencias externas

## Regla

Si una automatizacion toca Airtable o scripts Python, deja esa relacion explicita como contrato.
